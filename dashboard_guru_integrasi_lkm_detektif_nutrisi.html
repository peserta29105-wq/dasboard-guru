Skrip Auto-Sync LKM Digital Murid

Tempelkan skrip JavaScript di bawah ini pada bagian <body> paling bawah di file lkm_digital_detektif_nutrisi.html milik murid. Skrip ini secara otomatis mendeteksi input, form, kalkulasi, serta refleksi murid dan mengirimkannya secara real-time ke Dashboard.

Petunjuk Tambahan: Skrip telah dikonfigurasi menggunakan backend Firestore bawaan. Semua data tersinkron secara terisolasi dan aman di bawah App ID detektif-nutrisi-app.
